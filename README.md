# AquaZen — Shopify 2.0 Theme

A lightweight, responsive Online Store 2.0 storefront inspired by a premium reusable-bottle landing page.

## Use

1. Push this repository to GitHub.
2. In Shopify admin, open **Online Store → Themes → Add theme → Connect from GitHub**.
3. Select the repository and branch, then customize all homepage sections in the theme editor.

The two original campaign assets live in `assets/aquazen-hero.png` and `assets/aquazen-lifestyle.png`. They are the default artwork and can be replaced through the relevant section settings.
